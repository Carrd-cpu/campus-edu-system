| 1  | 学院 → 专业 → 班级 → 学期 → 课程 → 开课 | 主数据一层层挂；删上层数据的校验，等下层模块写完再回改 |

## 1. 项目是什么

做一套**校园教务 / 学生成绩管理系统**，前后端分离，并带**校园 Agent 助手**：

| 端       | 地址                            | 谁用   | 做什么                            |
| ------- | ----------------------------- | ---- | ------------------------------ |
| 用户端（学生） | `http://127.0.0.1:5173/user`  | 学生   | 查成绩、课表、成绩单、公告、学习计划、校园助手        |
| 管理端（教务） | `http://127.0.0.1:5173/admin` | 管理员  | 学院/专业/班级/课程/开课/录成绩、公告、文档库、首页统计 |
| 后端 API  | `http://localhost:8080/api`   | 前端调用 | 教务业务 + 成绩计算 + AI 助手编排          |

**校园助手**是后端里的「小 Agent」：

1. 看懂问题（成绩？课表？补考？校规？）
2. **Tool Calling**：调用内部工具查**当前登录学生**的真实数据
3. **RAG**：检索校规 / 文档库切块
4. 有 DeepSeek 密钥时经 **Spring AI** 组织回答，没有则本地拼接

## 3. 技术栈小白解释

### 3.1 后端

| 技术                | 干什么                           |
| ----------------- | ----------------------------- |
| Spring Boot 3.3   | Java Web 框架，写 REST 接口         |
| MyBatis-Plus      | 简化教务表增删改查                     |
| MySQL             | 关系型数据库                        |
| JWT（jjwt）         | 登录后发令牌（脚手架已集成，业务接口直接用）        |
| Spring Validation | 校验请求参数                        |
| Lombok            | 少写 getter/setter              |
| JdbcTemplate      | 复杂联表查询（成绩列表、统计等）              |
| Spring AI         | 经 OpenAI 兼容协议调用 DeepSeek 聊天模型 |

### 3.2 前端

| 技术           | 干什么                                      |
| ------------ | ---------------------------------------- |
| Vue 3        | 页面框架（Composition API + `<script setup>`） |
| Vite         | 前端开发服务器、打包                               |
| Vue Router   | 路由（`/user`、`/admin`）                     |
| Pinia        | 存登录状态、系统名                                |
| Element Plus | 表格、按钮、弹窗、分页等 UI                          |
| Axios        | 调后端 API（脚手架已封装 `request`）                |
| ECharts      | 管理端首页统计图表                                |

### 3.3 本系统业务相关

| 能力         | 怎么做                                      | 关键类                                                 |
| ---------- | ---------------------------------------- | --------------------------------------------------- |
| 总评 / 绩点    | 平时 30% + 期末 70%，四分制绩点                    | `GradeRules`                                        |
| RAG 知识库    | 文档切块 → 字块重合打分检索（不用向量库）                   | `KnowledgeChunker`、`TextRanker`、`IKnowledgeService` |
| 校园助手 Agent | 工具编排查本人数据 + RAG + 可选 DeepSeek（Spring AI） | `CampusAgentService`                                |
| 学期过滤       | 解析「第一学期 / 本学期」，避免串学期                     | `SemesterResolver`                                  |
| 学习计划       | 学生对助手生成的计划落库、列表与删除                       | `IStudyPlanService`                                 |

**说明**：本项目**没有用 MCP**。助手工具就是 Java 方法调用。成绩必须绑定登录学生，不适合做成开放 MCP。

### 5.2 与本系统相关的配置

重点看数据源和 DeepSeek（Spring AI）：

```yaml
spring:
  ai:
    openai:
      api-key: ${DEEPSEEK_API_KEY:你的密钥}
      base-url: https://api.deepseek.com
      chat:
        options:
          model: deepseek-chat
  datasource:
    url: jdbc:mysql://localhost:3306/student_grade?createDatabaseIfNotExist=true&useUnicode=true&characterEncoding=UTF-8&serverTimezone=Asia/Shanghai&allowPublicKeyRetrieval=true&useSSL=false

  servlet:

  deepseek:
    enabled: true
```

### 2.2 教务校验工具 EduText（完整）

```java
package com.scaffold.service;

import cn.hutool.core.util.StrUtil;
import com.scaffold.common.BusinessException;

import java.math.BigDecimal;

/** 教务模块校验小工具 */
public final class EduText {
    private EduText() {
    }

    public static void requireText(String value, String message) {
        if (StrUtil.isBlank(value)) {
            throw new BusinessException(message);
        }
    }

    public static void checkScoreRange(BigDecimal value, String label) {
        if (value == null) {
            throw new BusinessException(label + "不能为空");
        }
        if (value.compareTo(BigDecimal.ZERO) < 0 || value.compareTo(new BigDecimal("100")) > 0) {
            throw new BusinessException(label + "须在 0 到 100 之间");
        }
    }
}
```

```java
    public List<ClazzView> listClasses() {
        Map<Long, EduMajor> majors = index(majorMapper.selectList(null), EduMajor::getId);
        Map<Long, EduCollege> colleges = index(collegeMapper.selectList(null), EduCollege::getId);
        Map<Long, Long> counts = new HashMap<>();
        List<User> members = userMapper.selectList(new LambdaQueryWrapper<User>()
                .select(User::getId, User::getClazzId)
                .isNotNull(User::getClazzId));
        for (User member : members) {
            counts.merge(member.getClazzId(), 1L, Long::sum);
        }
        List<EduClazz> clazzes = clazzMapper.selectList(new LambdaQueryWrapper<EduClazz>()
                .orderByDesc(EduClazz::getGradeYear)
                .orderByAsc(EduClazz::getId));
        List<ClazzView> views = new ArrayList<>();
        for (EduClazz clazz : clazzes) {
            EduMajor major = majors.get(clazz.getMajorId());
            EduCollege college = major == null ? null : colleges.get(major.getCollegeId());
            if (major == null || college == null) {
                continue;
            }
            ClazzView view = new ClazzView();
            view.setId(clazz.getId());
            view.setMajorId(clazz.getMajorId());
            view.setCollegeId(major == null ? null : major.getCollegeId());
            view.setName(clazz.getName());
            view.setMajorName(major == null ? "" : major.getName());
            view.setCollegeName(college == null ? "" : college.getName());
            view.setGradeYear(clazz.getGradeYear());
            view.setCounselor(clazz.getCounselor());
            view.setStudentCount(counts.getOrDefault(clazz.getId(), 0L));
            views.add(view);
        }
        return views;
    }

    public PageResult<ClazzView> pageClasses(String keyword, int page, int size) {
        int safePage = Math.max(page, 1);
        int safeSize = Math.min(Math.max(size, 1), 100);
        List<ClazzView> all = listClasses();
        String text = keyword == null ? "" : keyword.trim().toLowerCase(Locale.ROOT);
        List<ClazzView> filtered = new ArrayList<>();
        for (ClazzView row : all) {
            if (text.isEmpty()
                    || contains(row.getName(), text)
                    || contains(row.getMajorName(), text)
                    || contains(row.getCollegeName(), text)
                    || contains(row.getCounselor(), text)
                    || (row.getGradeYear() != null && String.valueOf(row.getGradeYear()).contains(text))) {
                filtered.add(row);
            }
        }
        return slice(filtered, safePage, safeSize);
```

```java
        int current = Math.max(pageNum, 1);
        int size = Math.min(Math.max(pageSize, 1), 100);
        LambdaQueryWrapper<EduSemester> q = new LambdaQueryWrapper<EduSemester>().orderByDesc(EduSemester::getId);
        if (StrUtil.isNotBlank(keyword)) {
            q.and(w -> w.like(EduSemester::getName, keyword).or().like(EduSemester::getCode, keyword));
        }
        return PageResult.of(semesterMapper.selectPage(new Page<>(current, size), q));
    }

    @Override
    public EduSemester save(EduSemester row) {
        EduText.requireText(row.getName(), "学期名称不能为空");
        EduText.requireText(row.getCode(), "学期编码不能为空");
        if (row.getCurrentFlag() == null) {
            row.setCurrentFlag(0);
        }
        if (row.getId() == null) {
            semesterMapper.insert(row);
        } else {
            semesterMapper.updateById(row);
        }
        if (row.getCurrentFlag() != null && row.getCurrentFlag() == 1) {
            markCurrent(row.getId());
        }
        return semesterMapper.selectById(row.getId());
    }

    @Override
    public void markCurrent(Long id) {
        EduSemester target = semesterMapper.selectById(id);
        if (target == null) {
            throw new BusinessException(404, "学期不存在");
        }
        List<EduSemester> all = semesterMapper.selectList(null);
        for (EduSemester item : all) {
            int flag = item.getId().equals(id) ? 1 : 0;
            if (item.getCurrentFlag() == null || item.getCurrentFlag() != flag) {
                item.setCurrentFlag(flag);
                semesterMapper.updateById(item);
            }
        }
    }

    @Override
    public void delete(Long id) {
        semesterMapper.deleteById(id);
    }
}
```

```java
    public List<OfferingView> listOfferings() {
        Map<Long, EduSemester> semesters = index(semesterMapper.selectList(null), EduSemester::getId);
        Map<Long, EduCourse> courses = index(courseMapper.selectList(null), EduCourse::getId);
        Map<Long, EduClazz> clazzes = index(clazzMapper.selectList(null), EduClazz::getId);
        List<EduOffering> offerings = offeringMapper.selectList(null);
        offerings.sort(Comparator
                .comparing((EduOffering row) -> flag(semesters.get(row.getSemesterId()))).reversed()
                .thenComparing(EduOffering::getSemesterId, Comparator.nullsLast(Comparator.reverseOrder()))
                .thenComparing(EduOffering::getClazzId, Comparator.nullsLast(Long::compareTo))
                .thenComparing(EduOffering::getCourseId, Comparator.nullsLast(Long::compareTo)));
        List<OfferingView> views = new ArrayList<>();
        for (EduOffering offering : offerings) {
            if (semesters.get(offering.getSemesterId()) == null
                    || courses.get(offering.getCourseId()) == null
                    || clazzes.get(offering.getClazzId()) == null) {
                continue;
            }
            views.add(toOffering(offering, semesters, courses, clazzes));
        }
        return views;
    }

    public PageResult<OfferingView> pageOfferings(String keyword, int page, int size) {
        int safePage = Math.max(page, 1);
        int safeSize = Math.min(Math.max(size, 1), 100);
        List<OfferingView> all = listOfferings();
        String text = keyword == null ? "" : keyword.trim().toLowerCase(Locale.ROOT);
        List<OfferingView> filtered = new ArrayList<>();
        for (OfferingView row : all) {

                    || contains(row.getCourseCode(), text)
                    || contains(row.getClazzName(), text)
                    || contains(row.getTeacherName(), text)
                    || contains(row.getSemesterName(), text)
                    || contains(row.getClassroom(), text)) {
                filtered.add(row);
            }
        }
```

```java
                .add(e.multiply(new BigDecimal("0.7")))
                .setScale(1, RoundingMode.HALF_UP);
    }

    public static BigDecimal point(BigDecimal total) {
        double score = total == null ? 0 : total.doubleValue();
        double point;
        if (score >= 90) {
            point = 4.0;
        } else if (score >= 85) {
            point = 3.7;
        } else if (score >= 82) {
            point = 3.3;
        } else if (score >= 78) {
            point = 3.0;
        } else if (score >= 75) {
            point = 2.7;
        } else if (score >= 72) {
            point = 2.3;
        } else if (score >= 68) {
            point = 2.0;
        } else if (score >= 64) {
            point = 1.5;
        } else if (score >= 60) {
            point = 1.0;
        } else {

        }
        return BigDecimal.valueOf(point).setScale(1, RoundingMode.HALF_UP);
```

```java
import com.scaffold.common.BusinessException;

import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.stereotype.Service;

@Service
public class ScoreServiceImpl implements IScoreService {

    @Autowired
    private EduScoreMapper scoreMapper;
    @Autowired
    private EduOfferingMapper offeringMapper;
    @Autowired
    private UserMapper userMapper;

    @Override
    public EduScore save(ScoreSaveRequest request) {
        if (request.getOfferingId() == null || request.getStudentId() == null) {
            throw new BusinessException("请选择开课和学生");
        }
        EduText.checkScoreRange(request.getUsualScore(), "平时成绩");
        EduText.checkScoreRange(request.getExamScore(), "期末成绩");
        EduOffering offering = offeringMapper.selectById(request.getOfferingId());
        if (offering == null) {
            throw new BusinessException(404, "开课不存在");
        }
        User student = userMapper.selectById(request.getStudentId());
        if (student == null) {
            throw new BusinessException(404, "学生不存在");
        }
        if (student.getClazzId() == null || !student.getClazzId().equals(offering.getClazzId())) {
            throw new BusinessException("该学生不在开课班级中");
        }
        EduScore existing = scoreMapper.selectOne(new LambdaQueryWrapper<EduScore>()
                .eq(EduScore::getOfferingId, request.getOfferingId())
                .eq(EduScore::getStudentId, request.getStudentId())
                .last("LIMIT 1"));
        EduScore row = existing == null ? new EduScore() : existing;
        row.setOfferingId(request.getOfferingId());
        row.setStudentId(request.getStudentId());
        row.setUsualScore(request.getUsualScore());
        row.setExamScore(request.getExamScore());
        row.setTotalScore(GradeRules.total(request.getUsualScore(), request.getExamScore()));
        row.setGradePoint(GradeRules.point(row.getTotalScore()));
        row.setRemark(request.getRemark());
        if (row.getId() == null) {
            scoreMapper.insert(row);
        } else {
            scoreMapper.updateById(row);
        }
        return scoreMapper.selectById(row.getId());
    }

    @Override
    public void delete(Long id) {
        scoreMapper.deleteById(id);
    }
}
```

```java
package com.scaffold.service.impl;

import cn.hutool.core.util.StrUtil;
import com.baomidou.mybatisplus.core.conditions.query.LambdaQueryWrapper;
import com.baomidou.mybatisplus.extension.plugins.pagination.Page;
import com.scaffold.common.BusinessException;
import com.scaffold.common.PageResult;
import com.scaffold.entity.EduNotice;
import com.scaffold.mapper.EduNoticeMapper;
import com.scaffold.service.EduText;
import com.scaffold.service.INoticeService;
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.stereotype.Service;

import java.util.List;

@Service
public class NoticeServiceImpl implements INoticeService {

    @Autowired
    private EduNoticeMapper noticeMapper;

    @Override
    public List<EduNotice> list() {
        return noticeMapper.selectList(new LambdaQueryWrapper<EduNotice>()
                .orderByDesc(EduNotice::getPinned)
                .orderByDesc(EduNotice::getId));
    }

    @Override
    public PageResult<EduNotice> page(String keyword, int pageNum, int pageSize) {
        int current = Math.max(pageNum, 1);
        int size = Math.min(Math.max(pageSize, 1), 100);
        LambdaQueryWrapper<EduNotice> q = new LambdaQueryWrapper<EduNotice>()
                .orderByDesc(EduNotice::getPinned)
                .orderByDesc(EduNotice::getId);
        if (StrUtil.isNotBlank(keyword)) {
            q.and(w -> w.like(EduNotice::getTitle, keyword).or().like(EduNotice::getPublisher, keyword));
        }
        return PageResult.of(noticeMapper.selectPage(new Page<>(current, size), q));
    }


    @Override
    public List<EduNotice> publishedList() {
        return noticeMapper.selectList(new LambdaQueryWrapper<EduNotice>()
                .eq(EduNotice::getStatus, 1)
                .orderByDesc(EduNotice::getPinned)
                .orderByDesc(EduNotice::getId));
    }

    @Override
    public EduNotice publishedOne(Long id) {
        EduNotice notice = noticeMapper.selectById(id);
        if (notice == null || notice.getStatus() == null || notice.getStatus() != 1) {
            throw new BusinessException(404, "公告不存在或未发布");
        }
        return notice;
    }

    @Override
    public EduNotice save(EduNotice row) {
        EduText.requireText(row.getTitle(), "公告标题不能为空");
        EduText.requireText(row.getContent(), "公告内容不能为空");
        if (row.getPinned() == null) {
            row.setPinned(0);
        }
        if (row.getStatus() == null) {
            row.setStatus(1);
        }
        if (StrUtil.isBlank(row.getPublisher())) {
            row.setPublisher("教务处");
        }
        if (row.getId() == null) {
            noticeMapper.insert(row);
        } else {
            noticeMapper.updateById(row);
        }
        return noticeMapper.selectById(row.getId());
    }

    @Override
    public void delete(Long id) {
        noticeMapper.deleteById(id);
    }
}
```

```java
@RestController
@RequestMapping("/admin/edu")
public class AdminEduMetaController {

    @Autowired

    @Autowired
    private IMajorService majorService;
    @Autowired
    private ISemesterService semesterService;
    @Autowired
```

```java
package com.scaffold.service.impl;

import cn.hutool.core.util.StrUtil;
import com.baomidou.mybatisplus.core.conditions.query.LambdaQueryWrapper;
import com.baomidou.mybatisplus.extension.plugins.pagination.Page;
import com.scaffold.common.BusinessException;
import com.scaffold.common.PageResult;
import com.scaffold.dto.AgentChatResponse;
import com.scaffold.edu.DocumentTextReader;
import com.scaffold.edu.KnowledgeChunker;
import com.scaffold.edu.TextRanker;
import com.scaffold.entity.KbChunk;
import com.scaffold.entity.KbDocument;
import com.scaffold.mapper.KbChunkMapper;
import com.scaffold.mapper.KbDocumentMapper;
import com.scaffold.service.IKnowledgeService;
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.beans.factory.annotation.Value;
import org.springframework.stereotype.Service;
import org.springframework.web.multipart.MultipartFile;

import java.io.ByteArrayInputStream;
import java.nio.file.Files;
import java.nio.file.Path;
import java.nio.file.Paths;
import java.util.ArrayList;
import java.util.Comparator;
import java.util.List;
import java.util.UUID;

@Service
public class KnowledgeServiceImpl implements IKnowledgeService {

    @Autowired
    private KbDocumentMapper documentMapper;
    @Autowired
    private KbChunkMapper chunkMapper;

    @Value("${app.upload.path:uploads}")
    private String uploadPath;

    /**
     * 查询全部
     */
    @Override
    public List<KbDocument> list() {
        return documentMapper.selectList(new LambdaQueryWrapper<KbDocument>().orderByDesc(KbDocument::getId));
    }

    @Override
    public PageResult<KbDocument> page(String keyword, int pageNum, int pageSize) {
        int current = Math.max(pageNum, 1);
        int size = Math.min(Math.max(pageSize, 1), 100);
        LambdaQueryWrapper<KbDocument> q = new LambdaQueryWrapper<KbDocument>().orderByDesc(KbDocument::getId);
        if (StrUtil.isNotBlank(keyword)) {
            q.and(w -> w.like(KbDocument::getTitle, keyword).or().like(KbDocument::getCategory, keyword));
        }
        return PageResult.of(documentMapper.selectPage(new Page<>(current, size), q));
    }


    /**
     * 新增或修改
     */
    @Override
    public KbDocument save(KbDocument row) {
        if (StrUtil.isBlank(row.getTitle())) {
            throw new BusinessException("文档标题不能为空");
        }
        if (StrUtil.isBlank(row.getContent())) {
            throw new BusinessException("文档内容不能为空");
        }
        if (StrUtil.isBlank(row.getCategory())) {
            row.setCategory("校规");
        }
        if (row.getStatus() == null) {
            row.setStatus(1);
        }
        if (row.getId() == null) {
            documentMapper.insert(row);
        } else {
            documentMapper.updateById(row);
        }
        rebuildChunks(row.getId(), row.getContent());
        return documentMapper.selectById(row.getId());
    }

    /**
     * 上传文件并入库
     */
    @Override
    public KbDocument importFile(MultipartFile file, String category) {
        if (file == null || file.isEmpty()) {
            throw new BusinessException("请选择文件");
        }
        if (file.getSize() > 20L * 1024 * 1024) {
            throw new BusinessException("文件不能超过 20MB");
        }
        String original = fileNameOf(file.getOriginalFilename());
        String ext = DocumentTextReader.extension(original);
        if (!ext.equals("txt") && !ext.equals("md") && !ext.equals("docx") && !ext.equals("pdf")) {
            throw new BusinessException("只支持 txt、md、docx、pdf");
        }
        try {
            byte[] bytes = file.getBytes();
            String text = DocumentTextReader.read(original, new ByteArrayInputStream(bytes));
            Path dir = Paths.get(uploadPath, "kb").toAbsolutePath().normalize();
            Files.createDirectories(dir);
            String stored = UUID.randomUUID() + "." + ext;
            Files.write(dir.resolve(stored), bytes);
            KbDocument row = new KbDocument();
            row.setTitle(titleOf(original));
            row.setCategory(categoryOf(category));
            row.setContent(text);
            row.setFileName(original);
            row.setFilePath("/uploads/kb/" + stored);
            row.setFileSize(file.getSize());
            row.setStatus(1);
            documentMapper.insert(row);
            rebuildChunks(row.getId(), text);
            return documentMapper.selectById(row.getId());
        } catch (BusinessException ex) {
            throw ex;
        } catch (Exception ex) {
            throw new BusinessException("文件入库失败：" + ex.getMessage());
        }
    }

    @Override
    public void updateStatus(Long id, Integer status) {
        KbDocument row = documentMapper.selectById(id);
        if (row == null) {
            throw new BusinessException(404, "文档不存在");
        }
        row.setStatus(status != null && status == 1 ? 1 : 0);
        documentMapper.updateById(row);
    }

    /**
     * 删除
     */
    @Override
    public void delete(Long id) {
        KbDocument row = documentMapper.selectById(id);
        chunkMapper.delete(new LambdaQueryWrapper<KbChunk>().eq(KbChunk::getDocumentId, id));
        documentMapper.deleteById(id);
        deleteStoredFile(row);
    }

    @Override
    public void rebuildChunks(Long documentId, String content) {
        chunkMapper.delete(new LambdaQueryWrapper<KbChunk>().eq(KbChunk::getDocumentId, documentId));
        List<String> pieces = KnowledgeChunker.chunk(content);
        int index = 0;
        for (String piece : pieces) {
            KbChunk chunk = new KbChunk();
            chunk.setDocumentId(documentId);
            chunk.setChunkIndex(index++);
            chunk.setContent(piece);
            chunkMapper.insert(chunk);
        }
    }

    @Override
    public void rebuild(Long id) {
        KbDocument row = documentMapper.selectById(id);
        if (row == null) {
            throw new BusinessException(404, "文档不存在");
        }
        if (StrUtil.isBlank(row.getContent())) {
            throw new BusinessException("文档内容为空，无法更新切块");
        }
        rebuildChunks(id, row.getContent());
    }

    @Override
    public int rebuildAll() {
        List<KbDocument> docs = list();
        int count = 0;
        for (KbDocument doc : docs) {
            if (StrUtil.isBlank(doc.getContent())) {
                continue;
            }
            rebuildChunks(doc.getId(), doc.getContent());
            count++;
        }
        return count;
    }

    @Override
    public List<AgentChatResponse.Citation> search(String query, int limit) {
        List<KbDocument> docs = documentMapper.selectList(new LambdaQueryWrapper<KbDocument>().eq(KbDocument::getStatus, 1));
        if (docs.isEmpty()) {
            return List.of();
        }
        record Hit(double score, KbDocument doc, KbChunk chunk) {
        }
        List<Hit> hits = new ArrayList<>();
        for (KbDocument doc : docs) {
            List<KbChunk> chunks = chunkMapper.selectList(new LambdaQueryWrapper<KbChunk>()
                    .eq(KbChunk::getDocumentId, doc.getId())
                    .orderByAsc(KbChunk::getChunkIndex));
            String titleNorm = TextRanker.normalize(doc.getTitle());
            String queryNorm = TextRanker.normalize(query);
            String expanded = expandQuery(query);
            boolean titleHit = !titleNorm.isEmpty() && !queryNorm.isEmpty()
                    && (titleNorm.contains(queryNorm) || queryNorm.contains(titleNorm));
            double titleBoost = titleTermBoost(queryNorm, titleNorm);
            for (KbChunk chunk : chunks) {
                String haystack = doc.getTitle() + " " + chunk.getContent();
                double score = Math.max(TextRanker.score(query, haystack), TextRanker.score(expanded, haystack));
                // 标题与提问高度重合时抬高分数，避免「文档标题就是问题」却未命中
                if (titleHit) {
                    score = Math.max(score, 4.5);
                }
                // 「绩点怎么算」对不上整句标题，但与《成绩与绩点计算办法》共享「绩点」
                if (titleBoost > 0) {
                    score = Math.max(score, titleBoost);
                }
                if (score >= 1.15) {
                    hits.add(new Hit(score, doc, chunk));
                }
            }
        }
        hits.sort(Comparator.comparingDouble(Hit::score).reversed());
        List<AgentChatResponse.Citation> citations = new ArrayList<>();
        for (Hit hit : hits) {
            if (citations.size() >= limit) {
                break;
            }
            boolean duplicated = citations.stream().anyMatch(item -> item.getTitle().equals(hit.doc.getTitle())
                    && item.getSnippet().equals(snippet(hit.chunk.getContent())));
            if (duplicated) {
                continue;
            }
            AgentChatResponse.Citation citation = new AgentChatResponse.Citation();
            citation.setTitle(hit.doc.getTitle());
            citation.setCategory(hit.doc.getCategory());
            citation.setSnippet(snippet(hit.chunk.getContent()));
            citations.add(citation);
        }
        return citations;
    }

    /** 口语问法改写，提升与制度文档标题/正文的重合 */
    private String expandQuery(String query) {
        if (query == null || query.isBlank()) {
            return "";
        }
        return query
                .replace("怎么算", "计算")
                .replace("如何计算", "计算")
                .replace("怎么计算", "计算")
                .replace("怎么评定", "评定")
                .replace("如何评定", "评定")
                .replace("怎么办", "补考 重修")
                .replace("有哪些", "规定");
    }

    /** 查询与标题共享有效二字词时给基础分，避免同主题问法漏召回 */
    private double titleTermBoost(String queryNorm, String titleNorm) {
        if (queryNorm == null || titleNorm == null || queryNorm.length() < 2 || titleNorm.length() < 2) {
            return 0;
        }
        int hits = 0;
        for (int i = 0; i < queryNorm.length() - 1; i++) {
            String bi = queryNorm.substring(i, i + 2);
            if (titleNorm.contains(bi)) {
                hits++;
            }
        }
        return hits > 0 ? 2.2 + Math.min(hits, 3) * 0.4 : 0;
    }

    private String snippet(String content) {
        if (content == null) {
            return "";
        }
        String text = content.replace('\n', ' ').trim();
        return text.length() <= 140 ? text : text.substring(0, 140) + "…";
    }

    private String fileNameOf(String original) {
        if (StrUtil.isBlank(original)) {
            return "未命名.txt";
        }
        String name = original.trim();
        int slash = Math.max(name.lastIndexOf('/'), name.lastIndexOf('\\'));
        if (slash >= 0) {
            name = name.substring(slash + 1);
        }
        return name.isEmpty() ? "未命名.txt" : name;
    }

    private String titleOf(String fileName) {
        String title = fileName;
        int dot = title.lastIndexOf('.');
        if (dot > 0) {
            title = title.substring(0, dot);
        }
        if (title.length() > 120) {
            title = title.substring(0, 120);
        }
        return title;
    }

    private String categoryOf(String category) {
        String text = StrUtil.isBlank(category) ? "教务" : category.trim();
        if (text.length() > 32) {
            text = text.substring(0, 32);
        }
        return text;
    }

    private void deleteStoredFile(KbDocument row) {
        if (row == null || StrUtil.isBlank(row.getFilePath()) || !row.getFilePath().startsWith("/uploads/kb/")) {
            return;
        }
        try {
            Path file = Paths.get(uploadPath).toAbsolutePath().normalize()
                    .resolve(row.getFilePath().substring("/uploads/".length()));
            Files.deleteIfExists(file);
        } catch (Exception ignored) {
            // 原文件删不掉时，库记录已经删除
        }
    }
}
```

```java
package com.scaffold.service.impl;

import cn.hutool.core.util.StrUtil;
import com.baomidou.mybatisplus.core.conditions.query.LambdaQueryWrapper;
import com.baomidou.mybatisplus.extension.plugins.pagination.Page;
import com.baomidou.mybatisplus.extension.service.impl.ServiceImpl;
import com.scaffold.common.BusinessException;
import com.scaffold.common.PageResult;
import com.scaffold.entity.EduStudyPlan;
import com.scaffold.mapper.EduStudyPlanMapper;
import com.scaffold.service.IStudyPlanService;
import org.springframework.stereotype.Service;

import java.time.LocalDateTime;

@Service
public class StudyPlanServiceImpl extends ServiceImpl<EduStudyPlanMapper, EduStudyPlan> implements IStudyPlanService {

    /**
     * 分页查询
     */
    @Override
    public PageResult<EduStudyPlan> page(Long userId, long pageNum, long pageSize) {
        long current = pageNum < 1 ? 1 : pageNum;
        long size = pageSize < 1 ? 10 : Math.min(pageSize, 20);
        Page<EduStudyPlan> page = page(new Page<>(current, size), new LambdaQueryWrapper<EduStudyPlan>()
                .eq(EduStudyPlan::getUserId, userId)
                .orderByDesc(EduStudyPlan::getId));
        return PageResult.of(page);
    }

    /**
     * 获取详情
     */
    @Override
    public EduStudyPlan detail(Long userId, Long id) {
        EduStudyPlan row = getById(id);
        if (row == null || !userId.equals(row.getUserId())) {
            throw new BusinessException(404, "学习计划不存在");
        }
        return row;
    }

    /**
     * 新增
     */
    @Override
    public EduStudyPlan save(Long userId, String content, boolean fromAssistant) {
        if (StrUtil.isBlank(content)) {
            throw new BusinessException("计划内容不能为空");
        }
        String text = content.trim();
        int limit = fromAssistant ? STORE_LIMIT : MANUAL_LIMIT;
        if (text.length() > limit) {
            throw new BusinessException("计划内容不能超过 " + limit + " 字");
        }
        EduStudyPlan row = new EduStudyPlan();
        row.setUserId(userId);
        row.setContent(text);
        row.setCreatedAt(LocalDateTime.now());
        save(row);
        return getById(row.getId());
    }

    /**
     * 删除自己的计划
     */
    @Override
    public void remove(Long userId, Long id) {
        EduStudyPlan row = detail(userId, id);
        removeById(row.getId());
    }
}
```

```vue
function planParts(content) {
  const lines = String(content || '').split(/\n+/).map((line) => line.trim()).filter(Boolean)

function parsePlan(content) {
  const lines = String(content || '').split(/\n/).map((line) => line.trim()).filter(Boolean)
  const blocks = []
  let title = ''
  let block = null
  for (const line of lines) {
    const heading = line.match(/^【(.+?)】\s*(.*)$/)
    if (heading) {
      block = { heading: heading[1], lines: heading[2] ? [heading[2]] : [] }
      blocks.push(block)
      continue
    }
    if (!title && !block) {
      title = line
      continue
    }
    if (!block) {
      block = { heading: '', lines: [] }
      blocks.push(block)
    }
    block.lines.push(line)
  }
  return { title, blocks }
}

function stepOf(line) {
  const matched = String(line || '').match(/^(.+?（.+?）)\s*[：:]\s*(.+)$/)
  if (!matched) return null
  return { name: matched[1], text: matched[2] }
}
```
